Detailed Description

template<>
class lcs::Expression< 1, LINE_EXPR, void, void >

A template class specialisation which encapsulates a expressions consisting of single lines. A user of libLCS will never need to use this class explicitly. Implicitly, this class is used everytime a bitselect operation is performed on bus objects.

void lcs::Expression< 1, LINE_EXPR, void, void >::operator= ( const DelayStatePair &  dsp  )  [inline]

Assignment operator for assignment with a delay-state pair. An example of usage of this overloaded assignment operator is as follows:

        lcs::Bus<3> b1;
        b1[1] = (5, lcs::HIGH);

In the second line of the above code snippet, an assignment is being made to the line-expression on the LHS with a delay-state pair in the RHS. The value of delay used here is 5 system time units. Note the use of the neccessary parentheses enclosing the delay-state pair.

Assignment operator for assignment with a delay-expression pair. An example of usage of this overloaded assignment operator is as follows:

        lcs::Bus<3> b1(0), b2(5);
        b1[1] = (5, b2[1] | b1[0]);

In the second line of the above code snippet, an assignment is being made to the line-expression on the LHS with a delay-expression pair in the RHS. The value of delay used here is 5 system time units. Note the use of the neccessary parentheses enclosing the delay-expression pair.
